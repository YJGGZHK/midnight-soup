HOW TO PLAY

一碗汤，两个故事。

你看到的是「汤面」，主持人知道的是「汤底」。通过提问，把隐藏的因果关系找出来。

  1. 每次问一个能用「是 / 不是」回答的问题。
  2. 主持人也可能回答「无关」或「无法确定」。
  3. 卡住了可以要提示，每局最多三个。
  4. 连接 Jev 后，点击「我要破案」提交完整推理。

所有提问与破案判断都由 Jev 完成，判断可能出错；提示与汤底以固定故事为准。

POWERED BY TYPESAFE-AI / JEV

让 Jev 来主持。

在项目根目录的 .env 中填入 Vercel AI Gateway Key，保存后点击下方按钮，无需重启。

AI_GATEWAY_API_KEY=你的Key

Key 仅由服务端读取，不发送给网页。自由问题及隐藏汤底会发送到 Vercel AI Gateway 进行评估。免费期限与实际计费以 Vercel 为准。
